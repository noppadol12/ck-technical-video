# เฟส 4 — หลังบ้านแอดมิน

เปิดที่ `https://ck-technical-video.pages.dev/admin` (หลังผูกโดเมนแล้วจะเป็น `https://video.ckaircond.com/admin`)
ล็อกอินด้วยอีเมลและรหัสผ่านของบัญชีแอดมินที่สร้างไว้ใน Supabase ตอนเฟส 1

## ติดตั้ง (ครั้งเดียว)

Supabase → **SQL Editor** → วางไฟล์ `supabase/phase4.sql` → **Run**
(เพิ่มฟังก์ชันเรียงลำดับวิดีโอและหมวดหมู่ ถ้าไม่รัน ปุ่มเลื่อนขึ้น/ลงจะ error)

## ทำอะไรได้บ้าง

| เมนู | ทำได้ |
| --- | --- |
| ภาพรวม | ลูกค้าที่ใช้งานได้, เข้าระบบ/ดูวิดีโอ 7 วัน, วิดีโอยอดนิยม 30 วัน, รหัสใกล้หมดอายุ, ลูกค้าที่ไม่ได้เข้านาน |
| ลูกค้า | เพิ่ม (รหัสอัตโนมัติ `CK-เบอร์โทร`), แก้ไข, เปลี่ยนรหัส, ตั้งวันหมดอายุ, ปิด/เปิดสิทธิ์, เตะออกจากทุกเครื่อง, คัดลอกข้อความส่ง LINE |
| วิดีโอ | เพิ่มด้วยลิงก์ Google Drive (เห็นรูปปกก่อนบันทึก), แก้ไข, ซ่อน/แสดง, เลื่อนลำดับ, ลบ (owner) |
| หมวดหมู่ | เพิ่ม, เปลี่ยนชื่อ, เลื่อนลำดับ, ลบ (owner — วิดีโอในหมวดย้ายไป "ทั่วไป") |
| รายงาน | การดูวิดีโอ / การเข้าระบบ ตามช่วงวันที่ + ค้นหา, ดาวน์โหลด Excel (CSV), ประวัติการแก้ไขของแอดมิน |

## ความปลอดภัย

- แอดมินล็อกอินผ่าน Supabase Auth แยกจากลูกค้า cookie ของลูกค้าใช้กับหลังบ้านไม่ได้
- cookie แอดมินอายุ 12 ชั่วโมง ส่งเฉพาะ `/api/admin` และใช้ `SameSite=Strict`
- รหัสผ่านผิด 5 ครั้งใน 15 นาที (ต่อ IP) ต้องรอ
- ทุกการแก้ไขถูกบันทึกในตาราง `admin_actions` (ดูได้ที่ รายงาน → ประวัติการแก้ไขของแอดมิน)
- ปิดบัญชีแอดมิน: ตั้ง `admins.active` = false มีผลทันที

## เพิ่มทีมงาน (staff) ภายหลัง

1. Supabase → **Authentication** → **Users** → **Add user** → ใส่อีเมลและรหัสผ่าน ติ๊ก **Auto Confirm User**
2. SQL Editor:

```sql
insert into public.admins (user_id, name, role)
select id, 'ชื่อทีมงาน', 'staff' from auth.users where email = 'อีเมลทีมงาน';
```

staff ทำได้ทุกอย่าง ยกเว้นลบวิดีโอและลบหมวดหมู่
